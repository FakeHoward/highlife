# MSC4139 — bot prompts in HighLife

HighLife renders `org.matrix.msc4139.prompts` on timeline events and replies
with `org.matrix.msc4139.conversation.reply` (`used_prompt` + `m.thread`).
Vendor `dev.aiomatrix.keyboard` / HMAC callbacks stay. Bots should dual-write
both shapes; this client accepts either.

Input prompts use a one-line prompt; preset prompts send the label immediately.
HMAC fail-closed E2EE for vendor callbacks is unchanged.
