# Security

## Reporting a vulnerability

Email the maintainers privately with a description of the issue, steps to reproduce, and impact. Do not open a public GitHub issue for security reports.

We will acknowledge receipt and follow up with next steps.

## Repository hardening notes

Branch protection on `main` should require pull requests and status checks before merge. Enable it in GitHub Settings → Branches (needs repo admin). Secret scanning is expected to stay on for this repository.
